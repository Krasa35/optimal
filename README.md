# Energy Optimalization of manipulator movement from point A to B
The project is under development, not all files are up to date and some of them may be not working. 
## UR5 manipulator Pick & Place example 
the example and utils used are based on the repository: [PaulDanielML/MuJoCo_RL_UR5](https://github.com/PaulDanielML/MuJoCo_RL_UR5)
## Crocoddyl CartPole example
The example and utils used are based on the repository: [loco-3d/crocoddyl](https://github.com/loco-3d/crocoddyl/tree/devel)
## Setup
File requirements.txt contains all the dependencies for the project. You can install them using pip:
```bash
pip install -r requirements.txt
```
